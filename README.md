# Hotty

Keep track of your keyboard shortcuts on the Mac: hotkeys, aliases, mouse buttons and trackpad gestures, grouped by app, with a keyboard map that shows which combos are taken, conflict detection and flashcards to practice them.

## Download

Get the latest `Hotty-<version>.dmg` from the [Releases](../../releases/latest) page, open it and drag **Hotty** onto **Applications**.

- Requires macOS 26 or later
- Signed and notarized by Apple
- Free to use
- Hotty checks this page for updates and can install them from inside the app (the update is verified with a signature)
